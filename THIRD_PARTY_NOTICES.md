# Avisos de terceros

El instalador de FileShift distribuye la aplicación, la extensión COM y el runtime .NET publicado con la aplicación. Consultá las licencias y avisos del runtime de Microsoft en su [repositorio oficial](https://github.com/dotnet/runtime).

El script de requisitos descarga los motores por separado desde sus proyectos o distribuidores. Las conversiones los invocan como procesos independientes. Consultá las condiciones de cada distribución en sus propios avisos.

- FFmpeg y ffprobe 9.0.2, compilación Windows Essentials de Gyan. Los componentes y opciones seleccionados por el distribuidor determinan la licencia del binario. [Distribución de Gyan](https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2)
- ImageMagick 7.1.2-35. Se usa para imágenes y para validar las páginas renderizadas del PDF. [Licencia de ImageMagick](https://imagemagick.org/script/license.php)
- Ghostscript 10.08.0, distribución AGPL de Artifex. Se usa para renderizar PDFs y verificar salidas PDF. [Distribución de Artifex](https://github.com/ArtifexSoftware/ghostpdl-downloads/releases/tag/gs10080)
- LibreOffice, instalación opcional del usuario. [Licencias de LibreOffice](https://www.libreoffice.org/about-us/licenses/)
